# AI-Assisted Development

AI assistance was used as a development aid.

Process:
1. Define the project requirements before generating code.
2. Generate small modules rather than one large program.
3. Review the generated code manually.
4. Run unit, integration and property-based tests.
5. Run mypy, ruff and black.
6. Fix errors found during validation.
7. Keep the final design understandable enough to explain during the technical defence.

Important: AI-generated code is treated as a suggestion and is validated before use.
